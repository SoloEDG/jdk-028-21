# LOGIC LAB

## 安装与本地启动

需要 Node.js 22 或更新版本。

```sh
npm install
npm run dev
```

打开终端显示的地址。类型检查和构建：

```sh
npm run typecheck
npm run build
```

## Docker 启动

```sh
docker compose up --build
```

浏览器打开 http://localhost:8028 。

## 电路代价与传播预算

右侧“电路代价”面板在信号观测之外给出代价分析：

- **总成本**：按每种门实例数 × 单件成本求和。
- **结构最长路径**：只按连线与延迟做拓扑 DP，不检验逻辑是否放行。
- **可激活最长路径**：确实存在某次**单输入翻转**能让该输出翻转的最长路径。
  分析会验证旁路电平、同源分叉的引脚不能独立变化，并把经过恒定阻断门的长支路
  排除在实际瓶颈之外。
- **每个目标输出**可单独设置最长传播预算；可激活路径超过预算即判为超预算，
  即使逻辑检测（真值表）全部正确也照常显示。
- 点击输出的可激活事件可在画布上高亮路径，并查看翻转前后的输入、旁路条件和
  逐级到达时间。
- 预算或门成本可随时调整且不改变电路逻辑，并可保存分析版本逐项对比。
- 计算未完成（反馈环、输入过多等）显示为“计算未完成”，与真正的超预算分开。

### 公布的默认代价

旧存档（没有 `analysis` 字段）使用下列默认值，单位一致、可复现：

| 元件 | 单件成本 | 输入→输出延迟 |
| ---- | -------: | ------------: |
| INPUT 输入开关 | 1 | 0 |
| OUTPUT 输出指示灯 | 1 | 1 |
| NOT 非门 | 1 | 1 |
| AND / OR / NAND / NOR | 2 | 2 |
| XOR 异或门 | 3 | 3 |

默认最长传播预算为 24。新设置与版本快照随实验一起保存/导出。
